For each topic, we recommend that the lead submits a Code Sprint Project Proposal to the [ioos-code-sprint](https://github.com/ioos/ioos-code-sprint) GitHub repository, identifying the scope of that topic. 
This will help ensure each code sprint topic has a plan that can be executed during the code sprint week.

Key dates for building the sprint topic agenda:
* **September 30, 2026** - Code Sprint Project Proposal Deadline.
* **October 2, 2026** - Community votes on topics of interest. (we will send a Google Form for voting)
* **October 9, 2026** - Top 10 sprint topics posted to the website. (identified from the survey above)

Current list of proposed topics can be found [here](https://github.com/ioos/ioos-code-sprint/issues?q=is%3Aissue+state%3Aopen+label%3A%22code+sprint+topic%22+label%3A2026).

Expectations for topic leads: Leads are expected to identify a plan for the code sprint topic, establish a team, and take the lead on executing said plan. See more information about participant expectations in the [participant guide](https://ioos.github.io/ioos-code-sprint/2026/participant-guide).

To submit topics of interest use the GitHub issue form below.
