During the ERDDAP breakout session at the Annual DMAC meeting, there was a suggestion to build some initial configuration to instruct AI agents on how to access and use IOOS (others too?) data. Initially the thought would be to have the configuration tell the AI agent what tools to use to access data, like erddapy for ERDDAP, and some other assumptions we make on a daily basis, like QARTOD rules maybe.

### Expected Outcomes

A collection of default instructions one could provide to an AI agent. Probably a collection of markdown files in a repository. 

* Gemini has [GEMS](https://gemini.google/overview/gems/).
* ChatGPT has [GPTS](https://chatgpt.com/gpts)
* Claude has [projects](https://support.claude.com/en/articles/9517075-what-are-projects)
